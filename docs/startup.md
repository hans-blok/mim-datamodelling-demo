# Startup

## Hoe begin je?

Om zelf mee te doen heb je een editor, een AI-assistent en de modelleertool nodig.

<div class="grid cards" markdown>

- **1. Installeer Visual Studio Code**

    Download de editor via [code.visualstudio.com](https://code.visualstudio.com/) en installeer die.

- **2. Maak een GitHub-account**

    Voor GitHub Copilot heb je een GitHub-account nodig. Heb je al een account, dan kun je dit overslaan.

- **3. Kies een Copilot-abonnement**

    Er is een gratis variant met beperkingen en er zijn betaalde abonnementen. Kijk op de pagina met [GitHub Copilot plans](https://docs.github.com/en/copilot/get-started/plans) wat nu beschikbaar is en wat het kost.

- **4. Installeer de extensies**

    Open in Visual Studio Code de weergave Extensies (`Ctrl+Shift+X`). Zoek en installeer GitHub Copilot, GitHub Copilot Chat en Factum. De extensie heet "Factum — Object-Role Modeling (ORM 2)" en komt van Volodymyr Pavlyshyn. Het is een visuele ORM 2-editor voor VS Code, nu nog in preview. Je tekent er conceptuele schema's mee, controleert ze en importeert NORMA .orm-bestanden.

- **5. Haal de repository binnen**

    Clone [de repository](https://github.com/hans-blok/mim-datamodelling-demo) en open de map in Visual Studio Code.

- **6. Maak je eerste model**

    Open het opdrachtenpalet met `F1` en typ `ORM`. Kies in de lijst de opdracht om een nieuw ORM-model te maken.

</div>

!!! note "Controleer de stappen"
    Deze uitleg is een eerste opzet. De abonnementen en voorwaarden van GitHub Copilot veranderen regelmatig. Factum is nog in preview, dus de werking kan veranderen. Controleer bij stap 6 de exacte naam van de opdracht in Factum.
